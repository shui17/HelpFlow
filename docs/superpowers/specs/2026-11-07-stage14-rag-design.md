# 阶段十四：RAG 客服回复助手设计

## 目标与范围

客服在本人负责、未关闭的工单详情生成回复建议，查看资料来源，将草稿填入现有编辑框，编辑后主动发送。沿用现有认证、公开回复和 SLA 逻辑。第一版非流式，不自动发送，不调用业务操作，不索引历史工单或内部备注。

当前用户选择 DeepSeek，但尚无 API Key。代码、测试与配置说明可先完成；真实模型联调和回答质量验收在用户本地配置凭据后完成。测试替身不作为产品模式，不把替身输出报告为真实模型结果。

## 方案选择

推荐 MySQL 保存资料与向量、应用内执行小规模余弦相似度检索。复用现有数据库与迁移，适合首批 5～10 篇 FAQ；限制有效分块总量为 1000，超过限制明确报错，不静默截断候选。该方案不承诺适合大规模知识库。

独立向量数据库便于后续扩容，但当前增加部署和一致性成本，暂不引入。仅关键词检索可以降低接入成本，但不满足本阶段 Embedding 学习与验收目标，不作为替代方案。

## 模型配置

生成使用 DeepSeek 官方 API；生成与 Embedding 分别配置 base URL、模型名称和密钥，凭据仅由后端环境变量读取。Embedding 使用独立的兼容 embeddings 接口服务，供应商由用户后续选择，不默认复用 DeepSeek 地址或密钥。

模型名称可配置；不得假定生成模型提供 Embedding。接口适配器负责响应校验、超时与错误转换。限制输入长度、输出长度和并发，生成请求不自动重试以避免重复费用。日志不记录密钥、工单正文或模型原始响应。

未配置模型时应用仍可启动，生成入口明确显示服务未配置；在线导入所需 Embedding 不可用时明确失败，支持只校验资料的离线命令。密钥不进入浏览器或 Git。

## 知识资料与导入

交付 5～10 篇与现有功能一致的原创 Markdown FAQ，以及固定评测问题集。Markdown 使用元数据头；TXT 使用同名 JSON 元数据文件。必填字段：稳定文档 ID、标题、正整数版本、审核状态、公开范围。仅 approved 且 public 的资料可激活。

按标题、段落和长度上限确定性分块，保留文档 ID、版本、标题、chunk_id、内容哈希。文档版本及其分块使用唯一约束；重复导入相同版本与内容不调用模型、不新增数据；同版本不同内容拒绝导入，要求提高版本。

数据库新增知识文档、版本和分块表。向量保存模型标识、服务标识、维度与内容哈希；校验非空、有限数值、维度一致与非零范数。切换 Embedding 模型或服务必须重建索引，不能混用旧向量。

调用 Embedding 时不持有数据库写锁。全部分块成功后，在短事务内保存新版本并切换有效版本；失败保留原有效版本。并发导入依赖唯一约束及文档锁，禁止旧版本覆盖新版本。提供停用文档命令，停用版本不参与检索。

## 检索、生成和权限

新增 POST /api/v1/tickets/{id}/reply-suggestion。仅当前负责客服可用，管理员保持既有无公开回复入口的规则。生成前检查账号启用、工单归属与未关闭状态；返回前重新读取并检查权限和上下文是否变化。转交、关闭或公开内容变化时丢弃旧结果，提示刷新后重试。

查询材料限于工单标题、描述和有明确条数、字符上限的近期公开回复；不发送内部备注、账号邮箱或其他工单资料。读取数据库后释放事务，再请求外部服务。

检索当前有效版本，默认 Top K 为 4，相似度阈值可配置并通过问题集校准。无符合条件资料时返回 insufficient_evidence，不调用生成模型。阈值不被解释为答案正确概率。

提示词将工单和检索片段作为不可信资料，要求依据资料回答、忽略资料中的操作指令、避免无依据承诺。输出包含草稿与引用 chunk_id；后端验证引用属于本次检索集合，不接受模型伪造标题或链接。返回来源标题、版本和片段，由数据库构造。有效引用并不证明内容正确，仍需人工审核。

草稿不超过现有回复 2000 字限制；空输出、无效引用、格式错误与超长结果明确失败。返回前确认使用的知识版本仍有效，避免展示已停用资料。

## 页面与发送

工单详情新增独立回复助手组件，包含生成按钮、加载状态、可重试错误、资料不足提示、草稿与来源。仅有资格的客服显示生成入口。

点击采用草稿才填入现有回复框；已有输入时先确认替换。生成结果不得直接发送。切换工单、离开页面或权限变化时清除结果，忽略迟到响应。发送复用现有接口并继续由后端重新鉴权；生成草稿不会触发首次公开响应 SLA。

## 验收与交付

- 新迁移在独立测试库执行升级和结构检查；不自动迁移现有业务库。
- 导入测试覆盖重复导入、版本更新、并发、停用、向量损坏、维度不符、模型变更和外部失败时旧版本保留。
- 接口测试覆盖未登录、普通用户、非负责客服、生成中转交或关闭、备注隔离、无资料、超时、无效引用与未配置服务。
- 前端测试覆盖加载与错误状态、采用草稿、已有输入保护、迟到结果及不自动发送。
- 现有后端与前端回归、生产构建、浏览器草稿到人工回复流程；清楚记录环境导致的跳过项。
- 固定问题集记录应命中文档，包含同义问法、超出知识范围和指令注入样例。真实模型配置后记录检索命中、来源有效性、人工核对的依据一致性、耗时与实际 token 使用；没有真实调用时不宣称质量验收通过。
- 交付导入/停用命令、FAQ、评测命令、环境变量示例、OpenAPI 与运行指南。保留工作区已有文档改动和数据库备份，不提交备份或凭据。
