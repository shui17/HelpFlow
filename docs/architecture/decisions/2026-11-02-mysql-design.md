## 文件与执行顺序

在 backend/sql/ 提供 01_schema.sql、02_seed.sql、03_queries.sql、04_indexes.sql、05_transactions.sql、06_crud.sql。建表脚本不删除已有数据库，遇到已有表直接报错；示例数据使用明确 ID，不覆盖已有记录。查询和索引脚本只读。事务演示使用独立的新工单，成功提交后制造唯一约束错误，自动回滚并验证状态和日志。CRUD 练习最后回滚。

## 数据和约束

InnoDB、utf8mb4、UTC、自增 BIGINT 主键。邮箱和工单号唯一，所有外键均有前导索引并限制级联删除。枚举用 VARCHAR 与 CHECK 表达。组合索引覆盖外键时不重复创建同列单字段索引。密码字段使用明确无效的学习占位值，不提供登录能力。

## 验证和交付

使用隔离的本地 MySQL 实例执行全部 SQL，检查表数量、查询结果、提交与回滚、唯一和外键约束、脚本重复执行行为；若环境不可用，明确报告未验证项。更新阶段四指南和项目文件关系图，保留 Word 路线原文。不创建 Git 提交。
